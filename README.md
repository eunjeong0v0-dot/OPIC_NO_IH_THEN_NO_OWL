# OPIC_NO_IH_THEN_NO_OWL

오순 님의 OPIc(오픽) 스피킹 시험 대비 학습 저장소입니다.

## 목표

- 목표 등급: IH (Intermediate High) 이상
- 서베이 기반 콤보셋 주제별 답변 준비
- 롤플레이(Role-Play) 및 돌발 질문 대응 연습

## 폴더 구조

```
.
├── memory-bank/       # 프로젝트 진행 상황과 맥락을 기록하는 메모리 뱅크
│   ├── projectbrief.md
│   ├── activeContext.md
│   ├── progress.md
│   └── studyNotes.md
└── topics/            # 콤보셋 주제별 답변/노트 (주제 추가 시 생성)
```

## 사용법

새 세션을 시작할 때 `memory-bank/` 폴더를 먼저 확인하면 이전 진행 상황을 빠르게 파악할 수 있습니다.
