## 답변 전략 (오픽노잼 스타일 참고)
※ 오픽노잼의 구체적 강의/교재 내용을 그대로 가져온 것이 아니라, 웹 검색으로 확인한 일반적인 특징을 참고한 방향성임.

- 수많은 질문을 몇 가지 큰 유형(묘사, 경험/에피소드, 습관/루틴, 비교 등)으로 단순화해서 접근
- 단순 사실 나열("집에서 공부해요")로 끝내지 않고, **이유 + 구체적 경험담(에피소드)**를 덧붙여 답변 완성도를 높임
- 필수 문장(도입 → 설명 → 경험 → 마무리)을 블록처럼 조합해 하나의 답변을 만들고, 다른 주제에도 재활용/확장
- 쉬운 단어와 짧은 문장 위주로, 실수 없이 끝까지 끊김 없이 말하는 것을 최우선으로 함
- 스크립트는 오순 님의 실제 이야기를 기반으로 작성 (암기 부담을 줄이고 진짜처럼 말할 수 있도록)
