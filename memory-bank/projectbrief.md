# 프로젝트 개요

## 누구를 위한 프로젝트인가
- 오순 (사용자)

## 목표
- OPIc 스피킹 시험 대비
- 목표 등급: IH (Intermediate High) 이상 — 현재 등급 정보 없음, 확인 필요

## 범위
- 서베이 선택 항목 기반 콤보셋 주제 답변 준비
- 롤플레이(Role-Play), 돌발 질문 대응 연습
- 자주 쓰는 표현/문형 정리

## 확인이 필요한 정보 (사용자에게 물어봐야 함)
- 현재 오픽 등급 또는 학습 경험 유무
- 서베이에서 선택한 주제(직업, 거주 형태, 취미/관심사, 여가 활동 등)
- 시험 예정일
- 선호하는 학습 방식 (스크립트 암기 vs 즉흥 말하기 연습 등)
