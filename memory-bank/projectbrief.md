# 프로젝트 개요

## 누구를 위한 프로젝트인가
- 오순 (사용자)

## 목표
- OPIc 스피킹 시험 대비
- 목표 등급: IH (Intermediate High) 이상
- 현재 등급: 오픽 응시 경험 없음 (첫 응시)
- 영어 기초: 수능 영어 2등급 — 문법/독해 기반은 있으나 스피킹(말하기 아웃풋) 경험 부족으로 추정
- 시험 예정: 다음 달 (2026년 10월 중, 정확한 날짜 미정)

## 학습자 상황 및 전략 방향
- 완전 노베이스가 아니라 "읽고 이해는 되지만 입으로 즉흥적으로 말한 경험이 적은" 상태로 추정됨
- 문법/어휘를 처음부터 배우기보다, 아는 지식을 빠르게 말로 꺼내는 **아웃풋 훈련**에 집중하는 것이 효율적
- 짧은 기간 안에서는 **콤보셋 예측 + 템플릿/스크립트 암기 및 체화** 전략과 병행하여 실전 말하기 연습(속도, 끊김 없이 말하기) 비중을 높임
- 발음/억양보다 문장 구조의 정확성과 유창하게 들리는 전달력(끊김 없이 말하기)에 우선순위
- 수능 2등급 기반이라면 한 달 집중 훈련으로 IH 목표가 노베이스보다는 현실적이나, 확실한 보장은 아님

## 범위
- 서베이 선택 항목 기반 콤보셋 주제 답변 준비
- 롤플레이(Role-Play), 돌발 질문 대응 연습
- 자주 쓰는 표현/문형 정리 (특히 노베이스에게 필요한 기초 문장 패턴부터)

## 서베이 & 난이도 확정 (2026-09-25, 최종)
참고: https://community.linkareer.com/employment_data/6059579

**직업/거주지 (12개 카운트에 포함되지 않는 별도 고정 항목)**
| 대분류 | 선택 |
|---|---|
| 직업 - 종사분야 | 일 경험 없음 |
| 직업 - 학생여부 | 아니요 |
| 직업 - 수강여부 | 수강 후 5년 이상 지남 |
| 거주지 | 개인 주택/아파트에 홀로 거주 |

**여가활동/취미/운동/휴가 (여기서 정확히 12개 선택)**
| 대분류 | 선택 | 개수 |
|---|---|---|
| 여가활동 | 영화보기, 카페/커피전문점 가기, 공원 가기, 해변 가기, 쇼핑하기 | 5 |
| 취미/관심사 | 음악 감상하기, 독서 | 2 |
| 운동 | 걷기, 조깅, 운동을 전혀 하지 않음 | 3 |
| 휴가/여행 | 국내여행, 집에서 보내는 휴가 | 2 |
| **합계** | | **12** |

- 신분(무직)·학생여부(아니요)·수강여부(5년 이상)는 실제로는 직장인이지만 업무/학업 관련 예측 불가 질문을 차단하기 위한 전략적 선택 (서베이는 채점과 무관)
- 거주지는 실제로는 남자친구와 동거 중이나, 룸메이트/가족 관련 질문 회피를 위해 "홀로 거주"로 선택
- 해외여행은 롤플레이·사고 경험담 등 추가 준비 부담이 있어 제외
- 쇼핑하기/독서/운동을 전혀 하지 않음은 준비 부담이 거의 없는 흔한 주제라 12개를 채우기 위해 추가
- 콘서트보기 대신 해변 가기로 변경 (오순 님이 연습하기 더 쉽다고 판단, 2026-09-26)
- 자가진단(난이도) 단계: 4단계 (중간)
- ※ 실제 접수 화면의 항목 문구가 위와 정확히 일치하는지는 접수 시 화면 캡처로 재확인 필요

## 확인이 필요한 정보 (사용자에게 물어봐야 함)
- 정확한 시험 날짜
- 하루에 학습 가능한 시간
- 선호하는 학습 방식 (스크립트 암기 vs 즉흥 말하기 연습 등)
